# Competition evidence map

This is a preparation checklist, not an awarded or predicted score. No implementation can guarantee first place.

| Criterion | Current evidence | Highest-value remaining work |
|---|---|---|
| Impact (25) | Costed NY/NJ actions and explicit projected before/after | Operator-reviewed problem and a measured pilot |
| Analytics (20) | 128 subsets, eight-match holdouts, 81 sensitivities | Arrival series, interventions evaluated out of sample |
| Innovation (15) | Budget choice with accessibility and disruption tradeoffs | Demonstrate one decision changed by the tool |
| Feasibility (15) | Unit arithmetic, cost ranges, owner/dependency register | Obtain quotations and written operational feedback |
| Legacy (10) | Repeatable event planning workflow | Test a second event with new inputs |
| Visualization (10) | Decision-first page, map, frontier, queues, source labels | Rehearse judges' route through three control changes |
| Pitch (5) | English narrative and timed script | Record a clear three-minute product walkthrough |

The strongest honest claim is an auditable decision workflow, not a certified forecast. Do not describe scenario gains as realized savings, assume sample spending predicts spectators, or hide the large rideshare transfer error.
