# EventFlow interface design

The September 15 UI update adapts the Swiss Modern typography, asymmetric composition and progressive reveal guidance from [frontend-slides](https://github.com/zarazhangrui/frontend-slides/blob/main/SKILL.md). This remains an interactive website; fixed 16:9 slides and slide navigation are not introduced.

The design uses Archivo display type, Work Sans body text, IBM Plex Mono labels, warm paper, dark ink and an orange Houston poster. A continuous metric strip leads into maps and the event brief. The brief uses a dark section with a light input surface. Charts and source disclosures retain their existing meaning.

The product flow remains Houston demonstration → event brief → prepared New York-region concert scenario. The UI does not call a language-model API. Existing model assumptions and exported calculations are unchanged by this visual update.

Validation: JavaScript syntax and whitespace checks passed. Browser access was denied by automatic approval review, so screenshots, phone rendering and visual overlap checks for this revision are not verified. Reduced-motion handling and narrow-screen layouts are implemented but are not a substitute for that pending visual check.
