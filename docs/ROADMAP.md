# EventFlow Roadmap after v0.9

## Phase 1 — Local evidence completion

- Build the full Houston Rice profile.
- Load official METRO GTFS.
- Build a reproducible Houston OSM network snapshot.
- Calibrate traffic baselines with Houston / TxDOT counts.
- Replace illustrative equity values with ACS / CDC SVI aggregation.

## Phase 2 — Operational evidence

- Verify Park & Ride capacities, site control and event-day availability.
- Add event-specific Shuttle dwell, fleet, labor and enforcement costs.
- Validate road-closure, curb-management and bus-lane assumptions.
- Replace planning-template owners and lead times with agency-confirmed values.

## Phase 3 — External validation

- Compare modeled bottlenecks with observed NRG special-event patterns.
- Conduct structured review with a transit, traffic or event-operations expert.
- Record parameter changes and reviewer decisions in the assumption registry.
- Add one contrasting host city using the same pipeline.

## Phase 4 — Competition submission

- Freeze a reproducible evidence snapshot.
- Export submission narrative and technical appendix.
- Deploy a hosted read-only demo with a preloaded Houston case.
- Produce pitch deck, demo script and short video.
- Rehearse Q&A on assumptions, feasibility, equity and transferability.
