# Report fonts

Noto Sans SC, SIL Open Font License 1.1 (see OFL.txt).
Source: https://github.com/google/fonts/tree/main/ofl/notosanssc

The upstream variable TrueType font was instantiated at weight 400 and 700 with fontTools. ReportLab embeds subsets in downloaded reports so Chinese and Latin text render consistently without installing fonts on the reader's computer.
